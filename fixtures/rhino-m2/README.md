# Rhino M2 acceptance files

Generated by `cargo run -p warp-import-3dm --example generate_fixtures` using the pinned openNURBS SDK. These are synthetic, freely reproducible test parts, not customer geometry.

- `parts-mm-v8.3dm`: millimeters, Rhino 8. Two block definitions, repeated and nested/mirrored/nonuniformly scaled instances; rational, periodic, mixed and loose curves; point; explicit planar mesh.
- `parts-inch-v6.3dm`: identical physical geometry encoded in inches, Rhino 6.
- `solids-v8.3dm`: the same base geometry plus a trimmed face with a hole, a spherical B-rep and an extrusion. A deliberately inaccurate render cache demonstrates why cached meshes are not trusted for machining.

See [M2 testing](../../docs/baselines/M2_RHINO_IMPORT.md).
